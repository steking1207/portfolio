SK2作品管理
有未發佈的變更

    從左側選一件作品編輯，或按「新增作品」。

    怎麼新增、編輯、刪除、下架作品

    1. 第一次使用：按右上角 ⚙，貼上 GitHub 權杖（建立方式見下方）。權杖只存在這台電腦的瀏覽器裡。
    2. 新增：按「＋ 新增作品」，填標題、年份、分類，把截圖拖進「圖片」區。第一張圖就是封面，可以拖曳調整順序。
    3. 編輯：點左側作品，直接改欄位。
    4. 下架：勾選「下架（不在網站顯示）」。資料和圖片都保留，之後取消勾選就會重新上架。
    5. 刪除：按作品頁最下方的「刪除這件作品」。發佈時會一併刪掉它的圖片檔。
    6. 精選：勾選「放在首頁精選」，並用數字決定順序（1 最前面）。建議 4 到 8 件。
    7. 發佈：按「發佈到 GitHub」。所有變更會變成一次 commit，GitHub Pages 約 1 分鐘後更新。

    線上狀態怎麼填

    • 上線中：網站還在、而且是你做的版本。填網址，網站會顯示「上線中 ↗」。
    • 已改版：網站還在，但已經改成別的設計。填網址，顯示「已改版 ↗」。
    • 不標示：已下線，或是 APP、平面這類沒有網址的作品。
    • Demo 網址：你自己放在 GitHub Pages 等地方的可操作版本，會顯示「線上 Demo ↗」。

    建立 GitHub 權杖

    1. 開啟 GitHub → Fine-grained personal access token。
    2. Repository access 選 Only select repositories，選 portfolio。
    3. Permissions → Repository permissions → Contents 設成 Read and write。
    4. 產生後複製，貼到 ⚙ 設定裡。

    沒有權杖也可以

    按「下載 works.json」，把檔案放到 repo 的 data/works.json，新圖片放進 images/works/作品代號/，再 commit。

    GitHub 連線設定

    權杖只存在這個瀏覽器（localStorage），不會寫進網站或 repo。在公用電腦上用完請按「清除權杖」。
