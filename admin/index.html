有未發佈的變更

    從左側選一件作品編輯，或按「新增作品」。

    怎麼新增、編輯、刪除、下架作品

    1. 登入：後台需要 GitHub 權杖才能進入，沒有這個 repo 寫入權限的人看不到內容，也改不了。沒勾「記住這台電腦」時，關掉瀏覽器就會自動登出。
    2. 新增：按「＋ 新增作品」，填標題、年份（跨年度的專案在後面填結束年份，網站會顯示成 2023–2025）、分類，點選角色與技術與工具（可複選，常用的前端技術、設計工具、平台已預先列好，新的在後面輸入後按 Enter），把截圖拖進「圖片」區。第一張圖就是封面，可以拖曳調整順序。每張圖下方可選外框（瀏覽器框、手機框、無外框）：桌面版網站長截圖選「瀏覽器框」，手機畫面選「手機框」。
    3. 編輯：點左側作品，直接改欄位。
    4. 同年份排序：在左側清單拖曳同一年份的作品，或用作品標題旁的 ↑↓ 調整，網站上同年份的作品會照這個順序排。
    5. 下架：勾選「下架（不在網站顯示）」。資料和圖片都保留，之後取消勾選就會重新上架。
    6. 刪除：按作品頁最下方的「刪除這件作品」。發佈時會一併刪掉它的圖片檔。
    7. 精選：到上方「首頁精選」分頁，拖曳或用 ↑↓ 調整順序、× 移除，下方選單加入新作品。也可以在作品頁勾選「放在首頁精選」。建議 4 到 8 件。
    8. 發佈：按「發佈到 GitHub」。所有變更會變成一次 commit，GitHub Pages 約 1 分鐘後更新。

    線上狀態怎麼填

    • 上線中：網站還在、而且是你做的版本。填網址，網站會顯示「上線中 ↗」。
    • 已改版：網站還在，但已經改成別的設計。填網址，顯示「已改版 ↗」。
    • 不標示：已下線，或是 APP、平面這類沒有網址的作品。
    • 多個網站：同一個專案有官網、產品網站、活動網站時，主網站的網址填在「線上狀態」，其他網站在「圖片」區下方按「＋ 新增網站」，每個網站會有自己的一區，填名稱、年份、狀態、網址，再把那個網站的圖片上傳或拖進該區。作品頁會依網站分段顯示，各自有連結。
    • Demo 網址：你自己放在 GitHub Pages 等地方的可操作版本，會顯示「線上 Demo ↗」。

    建立 GitHub 權杖

    1. 開啟 GitHub → Fine-grained personal access token。
    2. Repository access 選 Only select repositories，選 portfolio。
    3. Permissions → Repository permissions → Contents 設成 Read and write。
    4. 產生後複製，貼到 ⚙ 設定裡。

    沒有權杖也可以

    按「下載 works.json」，把檔案放到 repo 的 data/works.json，新圖片放進 images/works/作品代號/，再 commit。
